== Cómo usar

Si deseas comenzar de inmediato, abre _project.godot_ ubicado en la carpeta _demo_ desde el editor de Godot Engine. (Las instrucciones sobre cómo ejecutar la demostración se proporcionan más adelante en este documento)

Si deseas usarlo en tu propio proyecto, copia el contenido de la carpeta _addons_ ubicada en la carpeta _demo_ al proyecto donde quieras usarlo.

Si ya existe una carpeta _addons_, copia el contenido de la carpeta _gd_cubism_.

NOTE: La carpeta _addons_ es una carpeta designada para almacenar programas que extienden el motor Godot, como GDCubism.

== Solución de problemas

==== El modelo no se carga correctamente

Si el nombre del archivo del modelo está en japonés, no se cargará correctamente. Sobrescribir el nombre del archivo generado por el Cubism Editor y la referencia en *.model3.json hará que funcione correctamente.

==== El parpadeo no ocurre normalmente

Es posible que los Ids para EyeBlink en *.model3.json no estén especificados. Configúralos y vuelve a exportar, o agrega ParamEyeLOpen y ParamEyeROpen a Ids.

==== La imagen aparece borrosa

Mipmap se ha habilitado para los shaders desde la versión 0.5.

Si deseas habilitarlo, vuelve a importar la textura utilizada en Live2D con Mipmap habilitado.

image::usage_mipmap_01.png[mipmap01,256]

El efecto de Mipmap es bastante significativo; sin embargo, dependiendo de la imagen, puede aparecer borrosa.

Sin aplicación de Mipmap

image::usage_mipmap_02a.jpg[mipmap02a,256]

Con aplicación de Mipmap

image::usage_mipmap_02b.jpg[mipmap02b,256]

==== Los modelos Live2D no se muestran al exportar proyectos

Los modelos Live2D utilizan varios archivos, que son procesados internamente por Live2D. En consecuencia, el motor Godot tiene dificultades para empaquetar eficazmente los recursos relacionados con Live2D.

Para garantizar un empaquetado adecuado, navega a la sección Recursos en la pantalla de Exportación. Aquí, especifica directamente los recursos que estás utilizando y la carpeta que los contiene.

Para obtener instrucciones detalladas, consulta la sección de opciones de Recursos en la documentación oficial sobre Exportación de proyectos:

https://docs.godotengine.org/ja/4.x/tutorials/export/exporting_projects.html#resource-options


== Acerca de la Demo

La carpeta _demo_ contiene los siguientes elementos como muestras. Para ejecutar cualquiera de las muestras, necesitarás el modelo Live2D de Nijiiro Mao.

Este modelo Live2D se puede descargar desde link:https://www.live2d.com[].

Organiza el contenido del archivo descargado de la siguiente manera:

* (_demo/examples/res/live2d_)
** mao_pro_jp
*** runtime
**** expressions
***** ...
**** map_pro_t02.4096
***** ...
**** motions
***** ...
**** mao_pro.cdi3.json
**** mao_pro.moc3
**** mao_pro.model3.json
**** mao_pro.physics3.json
**** mao_pro.pose3.json
*** mao_pro_t05.can3
*** mao_pro_t05.cmo3

Si deseas probar con tu propio modelo, coloca los archivos de salida siguiendo la estructura anterior en _demo/examples/res/live2d_.

|Esta es una muestra que también sirve como visor simple. Puedes reproducir _Expression_ y _Motion_.
