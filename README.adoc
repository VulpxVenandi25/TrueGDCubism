== Acerca de GDCubism

GDCubism es una extensión **no oficial** de Godot Engine 4.3+ que permite utilizar el
https://www.live2d.com/download/cubism-sdk/[Live2D Cubism SDK] desde GDScript o C#.

Internamente utiliza el https://github.com/Live2D/CubismNativeFramework[Cubism Native Framework] de Live2D Inc.

[IMPORTANT]
====
No contacte a Live2D Inc. respecto a GDCubism. Este es un proyecto comunitario independiente.
====

== Requisitos

* Godot Engine 4.3 o superior
* Live2D Cubism SDK (incluido en `thirdparty/`)
* Python 3.x (para SCons)
* Compilador de C++ compatible (MSVC en Windows, Clang/GCC en Linux/macOS)

== Estructura del proyecto

```
gd_cubism/
├── demo/                    # Proyecto de demostración de Godot
│   └── addons/gd_cubism/    # Plugin compilado (cópialo a tu proyecto)
│       ├── bin/             # DLLs compiladas
│       ├── example/         # Escenas y scripts de ejemplo
│       ├── res/             # Shaders y recursos
│       └── gd_cubism.gdextension  # Archivo de configuración del plugin
├── src/                     # Código fuente C++ de la extensión
├── godot-cpp/               # Bindings de Godot para C++ (submódulo)
├── thirdparty/              # Dependencias externas
│   ├── CubismSdkForNative-*-r.*/  # Live2D Cubism SDK
│   └── CubismNativeFramework/     # Framework nativo de Live2D
└── SConstruct               # Script de compilación (SCons)
```

== Cómo compilar

=== Windows

[source,bash]
----
scons platform=windows arch=x86_64 target=template_debug
scons platform=windows arch=x86_64 target=template_release
----

=== macOS

[source,bash]
----
scons platform=macos arch=arm64 target=template_debug
scons platform=macos arch=arm64 target=template_release
----

=== Linux

[source,bash]
----
scons platform=linux arch=x86_64 target=template_debug
scons platform=linux arch=x86_64 target=template_release
----

Las DLLs compiladas se generan en `demo/addons/gd_cubism/bin/`.

== Cómo agregarlo a tu proyecto de Godot

1. Compila la extensión (ver sección anterior) o descarga una versión precompilada.
2. Copia la carpeta `demo/addons/gd_cubism/` completa a la carpeta `addons/` de tu proyecto.
3. Abre tu proyecto en Godot 4.3+.
4. Ve a **Proyecto → Configuración del proyecto → Plugins** y activa **GDCubism**.
5. El plugin estará listo para usar.

También puedes simplemente copiar los archivos sin activar el plugin desde el editor:
- La carpeta `addons/gd_cubism/` con su `gd_cubism.gdextension` es suficiente para que Godot cargue la extensión automáticamente.

== Cómo usar GDCubism desde GDScript

=== 1. Crear un modelo Live2D en la escena

Puedes agregar un nodo `GDCubismUserModel` directamente desde el editor:

- Haz clic en **Añadir nodo** → buscar `GDCubismUserModel`.
- Asigna la propiedad `assets` con la ruta a tu archivo `.model3.json`.

O desde código:

[source,gdscript]
----
var model = GDCubismUserModel.new()
model.assets = "res://models/MiModelo/MiModelo.model3.json"
add_child(model)
----

=== 2. Reproducir animaciones

[source,gdscript]
----
# Obtener lista de animaciones disponibles
var motions = model.get_motions()
# motions es un diccionario: { "grupo": cantidad }

# Reproducir una animación
model.start_motion("grupo", 0, GDCubismUserModel.PRIORITY_FORCE)

# Reproducir en bucle
model.start_motion_loop("grupo", 0, GDCubismUserModel.PRIORITY_FORCE)

# Detener animaciones
model.stop_motion()
----

=== 3. Expresiones faciales

[source,gdscript]
----
# Obtener lista de expresiones
var expressions = model.get_expressions()

# Activar una expresión
model.start_expression("nombre_expresion")

# Detener expresión
model.stop_expression()
----

=== 4. Parámetros y opacidad de partes

[source,gdscript]
----
# Obtener parámetros del modelo
var params = model.get_parameters()
for p in params:
    print(p.name, " = ", p.value)

# Obtener opacidad de partes
var parts = model.get_part_opacities()
for p in parts:
    print(p.name, " = ", p.value)
----

=== 5. Efectos disponibles

El plugin incluye varios efectos que se pueden agregar como hijos del `GDCubismUserModel`:

* `GDCubismEffectBreath` — Respiración del personaje
* `GDCubismEffectEyeBlink` — Parpadeo automático de ojos
* `GDCubismEffectHitArea` — Áreas de colisión para interacción
* `GDCubismEffectTargetPoint` — Seguimiento visual (mirada que sigue al mouse)
* `GDCubismEffectCustom` — Efecto personalizado con señales

Ejemplo:

[source,gdscript]
----
var eye_blink = GDCubismEffectEyeBlink.new()
model.add_child(eye_blink)

var hit_area = GDCubismEffectHitArea.new()
hit_area.target = "AreaColision"
model.add_child(hit_area)
----

=== 6. Señales (motion_finished, motion_event)

[source,gdscript]
----
model.motion_finished.connect(_on_motion_finished)
model.motion_event.connect(_on_motion_event)

func _on_motion_finished():
    print("Animación terminada")

func _on_motion_event(event_value: String):
    print("Evento: ", event_value)
----

== Modo de renderizado

A partir de la versión 0.9, GDCubism utiliza renderizado directo en lugar de SubViewports, lo que reduce significativamente la carga de procesamiento y el consumo de memoria GPU.

Si deseas el comportamiento anterior (con SubViewport), coloca el `GDCubismUserModel` dentro de un nodo `SubViewport`.
