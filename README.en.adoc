== About GDCubism

This software (GDCubism) is an **unofficial** GDExtension that makes the
https://www.live2d.com/download/cubism-sdk/[Live2D Cubism SDK] accessible from GDScript or C#.

[NOTE]
====
This GDExtension is available for use with Godot Engine 4.3 and above.
====

[IMPORTANT]
====
Starting from version 0.9, the rendering method has been switched to direct rendering, significantly reducing the processing load on the Godot Engine and GPU memory consumption. +
If you wish to handle it as before, place the _GDCubismUserModel_ under a _SubViewport_.
====

Internally, GDCubism uses the https://github.com/Live2D/CubismNativeFramework[Cubism Native Framework] published by Live2D Inc. +
Please do not contact Live2D Inc. regarding GDCubism.

== Project structure

```
gd_cubism/
├── demo/                    # Godot demo project
│   └── addons/gd_cubism/    # Compiled plugin (copy to your project)
│       ├── bin/             # Compiled shared libraries (DLLs)
│       ├── example/         # Example scenes and scripts
│       ├── res/             # Shaders and resources
│       └── gd_cubism.gdextension  # Plugin configuration file
├── src/                     # C++ extension source code
├── godot-cpp/               # Godot C++ bindings (submodule)
├── thirdparty/              # External dependencies
│   ├── CubismSdkForNative-*-r.*/  # Live2D Cubism SDK
│   └── CubismNativeFramework/     # Live2D Native Framework
└── SConstruct               # Build script (SCons)
```

== Building

=== Windows

[source,bash]
----
scons platform=windows arch=x86_64 target=template_debug
scons platform=windows arch=x86_64 target=template_release
----

=== macOS

[source,bash]
----
scons platform=macos arch=arm64 target=template_debug
scons platform=macos arch=arm64 target=template_release
----

=== Linux

[source,bash]
----
scons platform=linux arch=x86_64 target=template_debug
scons platform=linux arch=x86_64 target=template_release
----

Compiled libraries are placed in `demo/addons/gd_cubism/bin/`.

== Adding to your Godot project

1. Build the extension (see above) or download a prebuilt release.
2. Copy the entire `demo/addons/gd_cubism/` folder into your project's `addons/` folder.
3. Open your project in Godot 4.3+.
4. Go to **Project → Project Settings → Plugins** and enable **GDCubism**.
5. The extension is ready to use.

The plugin is automatically loaded from the `.gdextension` file; enabling it in the plugin list is optional.

== Using GDCubism from GDScript

=== 1. Add a Live2D model to the scene

Add a `GDCubismUserModel` node from the editor:

- Click **Add Node** → search for `GDCubismUserModel`.
- Set the `assets` property to your `.model3.json` path.

Or from code:

[source,gdscript]
----
var model = GDCubismUserModel.new()
model.assets = "res://models/MyModel/MyModel.model3.json"
add_child(model)
----

=== 2. Playing animations

[source,gdscript]
----
# List available motions
var motions = model.get_motions()
# Returns a dictionary: { "group": count }

# Play a motion
model.start_motion("group", 0, GDCubismUserModel.PRIORITY_FORCE)

# Play on loop
model.start_motion_loop("group", 0, GDCubismUserModel.PRIORITY_FORCE)

# Stop all motions
model.stop_motion()
----

=== 3. Facial expressions

[source,gdscript]
----
# List expressions
var expressions = model.get_expressions()

# Start an expression
model.start_expression("expression_name")

# Stop expression
model.stop_expression()
----

=== 4. Parameters and part opacity

[source,gdscript]
----
# Get model parameters
var params = model.get_parameters()
for p in params:
    print(p.name, " = ", p.value)

# Get part opacities
var parts = model.get_part_opacities()
for p in parts:
    print(p.name, " = ", p.value)
----

=== 5. Built-in effects

Add these as children of `GDCubismUserModel`:

* `GDCubismEffectBreath` — Character breathing
* `GDCubismEffectEyeBlink` — Automatic eye blinking
* `GDCubismEffectHitArea` — Collision areas for interaction
* `GDCubismEffectTargetPoint` — Visual tracking (eyes follow mouse)
* `GDCubismEffectCustom` — Custom effect with signals

Example:

[source,gdscript]
----
var eye_blink = GDCubismEffectEyeBlink.new()
model.add_child(eye_blink)

var hit_area = GDCubismEffectHitArea.new()
hit_area.target = "CollisionArea"
model.add_child(hit_area)
----

=== 6. Signals (motion_finished, motion_event)

[source,gdscript]
----
model.motion_finished.connect(_on_motion_finished)
model.motion_event.connect(_on_motion_event)

func _on_motion_finished():
    print("Motion finished")

func _on_motion_event(event_value: String):
    print("Event: ", event_value)
----
